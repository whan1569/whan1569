# 이동환 | Donghwan Lee

이 GitHub는 완성작만 전시한 포트폴리오가 아니라,  
문제를 발견하고, 직접 구현해보고, 실제 사용 여부와 한계를 판단한 기록입니다.

프로젝트를 단순히 “완성 / 미완성”으로 나누지 않습니다.  
대신 아래 기준으로 분류합니다.

| 분류 | 의미 |
|---|---|
| 실제 사용 중 | 지금도 직접 사용하거나 계속 개선 중인 프로젝트 |
| 완성 후 사용 보류 | 핵심 기능은 구현했지만 현재는 운영하지 않는 프로젝트 |
| 한계 확인 후 중단 | 기술 가능성은 검토했지만 효율·비용·검증 한계로 중단한 프로젝트 |
| 학습 / 구조 실험 | 특정 기술이나 구조를 이해하기 위해 만든 프로젝트 |
| 활동 / 실무 기록 | 코드보다 경험, 문서, 현장 대응, 교육 산출물이 중요한 저장소 |

## Woojin_works

PLC/C 기반 산업 장비 제어 로직, I/O 매핑, 상태 전이, 현장 디버깅, SVN 관리 등을 기록한 실무 저장소입니다.

- B&R PLC / Automation Studio 기반 제어 작업
- C 기반 사출기 제어 로직 분석 및 수정
- I/O 매핑, 출력 조건, 상태 전이 로직 정리
- 현장 테스트 및 수정 보고서성 문서 정리

**상태**  
실무 사용 / 현장 대응 기록 / 계속 누적 중

## Coin

바이낸스 선물 시장의 롱숏 비율, 포지션 비율, 미결제약정, 펀딩비 등을 수집하고 시각화하기 위한 개인 시장 분석 도구입니다.

- Binance API 기반 시장 데이터 수집
- Long/Short Ratio, Open Interest, Funding Rate 분석
- Streamlit 기반 실시간/히스토리 뷰어 구성
- 개인 매매 판단 보조용 데이터 구조 실험

**상태**  
실제 사용 중 / 시장 관찰 도구 / 계속 개선 중

<summary><strong>2. 완성 후 사용 보류</strong></summary>

## UN_Comtrade_Collector

UN Comtrade API를 활용해 국가, HS Code, 운송 방식 기준의 수출입 데이터를 수집하고 분석하기 위한 프로젝트입니다.

- 국가/HS Code/운송 방식 기준 무역 데이터 수집
- CSV 캐싱
- API 제한 대응
- Streamlit 기반 대시보드 구성

**보류 이유**  
데이터 도구는 구성했지만, 실제 사업 검증에서는 물류, 유통기한, 포워더, 도매 라인 등 데이터 외 조건이 더 중요하다고 판단했습니다.

**상태**  
완성형 데이터 도구 / 현재 사용 보류

---

## TOPIK

TOPIK 시험의 문제 번호별 고정 출제 유형을 활용해 규칙 기반 학습 추천 구조를 실험한 프로젝트입니다.

- 모의시험 응시 기능
- 정답/오답 판별
- 문제 번호 기반 유형 분류
- 취약 유형 분석
- 유사 유형 문제 재노출 흐름 설계

**보류 이유**  
핵심 추천 구조는 구현했지만, 실제 서비스화를 위해서는 문제 데이터 확보, UI 개선, 사용자 관리, 보안, 운영 비용이 추가로 필요하다고 판단했습니다.

**상태**  
교육 서비스 프로토타입 / 완성 후 운영 보류

</details>

<summary><strong>3. 한계 확인 후 중단</strong></summary>

## VisionDrive_Risk

모바일 카메라와 Optical Flow 기반 움직임 분석으로 사고 전조 판단이 가능한지 검토한 프로젝트입니다.

- Optical Flow 기반 이동 흐름 분석
- React Native / Expo 카메라 연결
- 모바일 센서 활용 가능성 확인
- 고성능 비전 모델 대비 비용과 효율 검토

**중단 이유**  
기술 가능성은 확인했지만, 직접 Optical Flow 기반으로 사고 전조를 판단하는 방식은 효율이 낮고 실제 서비스화 비용이 크다고 판단했습니다.

**상태**  
기술 검토 완료 / 한계 확인 후 중단

---

## AutoBid_Bot

상품 군집화, CTR/CVR 분석, 동적 입찰가 조정 구조를 활용해 광고비 최적화 시스템이 가능한지 검토한 프로젝트입니다.

- 유사 상품 군집화
- CTR/CVR 기반 광고 성과 분석
- 실시간 입찰가 조정 알고리즘 구조 검토
- 백테스트 한계 정리

**중단 이유**  
실제 광고 성과 데이터 확보와 검증 가능한 백테스트 환경이 부족하면 시스템 신뢰도가 떨어진다고 판단했습니다.

**상태**  
광고 입찰 구조 검토 / 한계 확인 후 중단

</details>
